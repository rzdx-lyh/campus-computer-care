## 2026-10-21 差异化功能（数字人助手 + 校园就近派单）

### 背景与目标

项目在 AI 诊断、本地 RAG、角色化、知识图谱、PWA、语音、工单闭环上已较完整。为在同类「校园电脑管家」作品中**脱颖而出**，本轮提出四个差异化功能方向：其中「数字人助手」「校园就近派单」两项已落地，「设备健康分趋势预警」「AI 看图/截图诊断」两项规划中（详见下方）。

### 一、数字人助手（拉高用户体验分）

- 新增 `src/components/mascot-assistant.tsx`：诊断页右侧萌宠 SVG 数字人。
- 状态随诊断过程自动变化：
  - **思考中**：天线闪烁 + 整体上下浮动（`mascot-bob` 动画）。
  - **已定位**：笑脸 + 绿色对勾徽标。
  - **需报修 / 高风险**：皱眉 + 橙色惊叹号徽标。
  - **朗读时**：嘴部 SMIL 动画「动嘴」，并提示「正在为你朗读」。
- 状态由 `src/app/diagnosis/page.tsx` 用 `useMemo` 推导：`isStreaming` → thinking；最后一条结果 `riskLevel==="high" || needRepair` → warning；有结果 → success；否则 idle。

### 二、校园就近派单（立校园记忆点）

- 新增 `src/lib/campus.ts`：纯逻辑层（楼宇坐标、维修员驻点、距离估算、就近推荐），无副作用可单测。
- 新增 `src/components/campus-map.tsx`：SVG 校园地图，标注 9 栋宿舍楼 + 工程中心维修驻点；维修员以绿/橙圆点区分空闲/忙碌。
- 行为：在 `/tickets/new` 填写宿舍楼号后，自动高亮「你的位置」，并画一条到**最近空闲维修员**的推荐连线（带流动小点动画），下方给出维修员姓名、擅长项、预计到场时长与派单理由。
- 推荐策略：优先空闲 → 其次在途工单少 → 最后按楼宇直线距离。全员忙碌时退化为最近维修员并说明。

### 三、设备健康分趋势 + 智能预警（规划中，未实现）

- 将「电脑体检」页已有的综合健康分存入 LocalStorage，按日期形成 7 天趋势线；低于阈值时弹出「预计 X 天后需维护」预警。
- 零额外 API、纯前端，可直接呼应管理端「AI 运维洞察」；把项目从「被动救火」升级为「主动预警」。
- 状态：规划中，尚未编写代码。

### 四、AI 看图 / 截图诊断（规划中，需评估）

- 上传蓝屏 / 报错截图，由 AI 识别故障。注意：当前 DeepSeek 文本模型**无视觉能力**，需接入多模态模型或 OCR 方案，会牵动额度与可用性。
- 稳妥替代：报错截图 OCR 提取文字 → 匹配本地知识库，惊艳度降一档但零模型依赖。
- 状态：规划中，尚未编写代码。

## 2026-10-21 数字人「整活」：眨眼 + 点击互动

### 背景与目标

首页首屏截图评审后，吉祥物虽然露出但偏静态。本轮让「小管家」真正活起来，提升答辩时的互动观感与记忆点。

### 改动内容（`src/components/mascot-assistant.tsx`）

1. **眨眼动画**：待机/思考态的眼睛由 `<circle>` 改为 `<ellipse>` + SMIL `animate`，`ry` 在 4.2s 周期内快速由 4 压到 0.4 再恢复，两只眼同步眨。
2. **待机浮动**：`mascot-bob` 动画从「仅思考时」扩展到「思考 + 待机」，静止时也有轻微呼吸感。
3. **点击互动（新增 `interactive` 属性）**：
   - 点击吉祥物 → 随机切换表情（`success` 笑脸 / `thinking` 思考）并冒一句俏皮话，3.2 秒后自动恢复默认文案。
   - 内置 8 条台词库（如「重启解决 80% 的问题，剩下 20% 交给我。」「C 盘红了不算绝症，我帮你瘦身。」）。
   - 鼠标悬停放大（`hover:scale-105`）、按下回弹；支持键盘 Enter/Space 触发（`role="button"` + `tabIndex`）。
   - 气泡底部提示「👆 点一下小管家，它会回你一句」。
   - 组件内部用 `useState` 管理 `bubble` / `reaction`，`useEffect` 同步外部 `message` 变化并在卸载时清理定时器。
4. **尺寸重构**：吉祥物渲染抽成 `renderMascot(sizeClass)`，hero 变体用 `size-24`、card 变体 `size-20`。
- `src/app/page.tsx`：首页 Hero 传入 `interactive` 开启互动。

## 2026-10-21 视觉重构：去掉「AI 生成感」，改为编辑式设计

### 背景与目标

原视觉是典型的模板化观感：蓝色渐变 Hero、居中三栏、统一 `rounded-2xl` + 柔阴影卡片、全大写色块标签、hover 浮起按钮。目标是改成**像人手工排版的产品**——有主次、有留白、有真实信息密度。

### 设计决策（反「AI 味」清单）

| AI 常见做法                 | 本轮改法                                        |
| ----------------------- | ------------------------------------------- |
| 蓝紫渐变 Hero + 光晕          | 纸感底色 `#f4f2ed` + 极淡 32px 网格，无渐变             |
| 全站居中、对称三栏               | 左对齐、不对称栅格（`1.6fr / 1fr`）                    |
| 统一大圆角 + 柔阴影             | 3px 小圆角 + 1px 细线边框，取消投影                     |
| 冷灰 slate                | 暖灰 slate 覆盖（`#ded9cf` 线 / `#75787f` 次级文字）    |
| 无衬线万能标题                 | 大标题用宋体/Georgia 衬线（`font-serif`）              |
| 全大写色块 eyebrow           | 等宽小字 kicker（`font-mono` + 字距，无背景色）          |
| 图标 + 圆角胶囊导航             | 纯文字导航，当前页用 2px 下划线标记                        |
| hover 上浮 `-translate-y` | 去掉浮起，改为颜色/下划线变化                             |
| emoji 装饰                | 移除，改用编号与真实数字                               |

### 改动文件

| 文件                               | 说明                                                                     |
| -------------------------------- | ---------------------------------------------------------------------- |
| `tailwind.config.ts`             | 新增 `sans/serif/mono` 字体族、`paper`/`ink`/`line` 色板；覆盖 `slate` 为暖灰；`shadow-soft` 压平 |
| `src/app/globals.css`            | 纸感网格背景、墨色文字、`surface-card` 细线化、新增 `.kicker`、按钮去掉浮起与投影                 |

| `src/components/site-header.tsx` | 实心纸感顶栏 + 2px 下边线；Logo 改墨底「管」字方块；导航去图标、改下划线激活态                        |
| `src/components/page-header.tsx` | 页面标题改衬线，下方加细线分隔                                                        |
| `src/app/layout.tsx`             | 页脚改细线 + 等宽小字                                                           |
