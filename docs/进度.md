## 2026-10-20 “网络错误”故障修复

### 根因

- `localhost:3000` 上仍运行旧构建的 `next start` 进程，根页面和 `/graph` 返回 500。
- 最新构建服务当时运行在 `3001`，因此页面表现为网络或服务错误。
- Service Worker 的 network-first 逻辑只对网络异常回退缓存，对服务器 5xx 响应不会回退缓存。

### 修复内容

- 停止 3000/3001 上的旧 Next.js 进程，重新执行 `npm run build`。
- 使用最新构建在 `localhost:3000` 启动生产服务。
- `public/sw.js` 缓存版本升级为 `campus-pc-care-v2`。
- 导航请求遇到 5xx 时也会优先返回已缓存页面，再返回服务器错误。
- 保留 `/api/` 不缓存及离线可读错误响应。

### 验证结果

- `npm run build`：通过。
- `GET /`：200。
- `GET /graph`：200。
- `GET /diagnosis`：200。
- `GET /manifest.webmanifest`：200。
- `GET /sw.js`：200，确认包含 `campus-pc-care-v2`。
- `GET /offline.html`：200。
- `POST /api/insight`：200。

### 浏览器注意事项

旧页面可能仍由上一版 Service Worker 控制。刷新页面后新 Service Worker 会自动安装并清理旧缓存；若浏览器仍显示旧资源，可在 DevTools 的 Application 面板执行一次 Unregister 并强制刷新。

### Service Worker 策略

- `install` 预缓存 `/`、`/graph`、`/diagnosis`、`/checkup`、`/manifest.webmanifest`、`/offline.html` 和图标。
- 额外解析页面 HTML 中的 `/_next/static/` JS/CSS 资源并缓存，保证离线刷新后仍可 hydration。
- 导航请求采用 network-first，失败时返回对应缓存页或 `offline.html`。
- `/_next/static/`、图标和 manifest 采用 cache-first。
- `/api/` 不缓存；离线请求返回 `503` 和可读 JSON 错误。
- `activate` 清理旧缓存并执行 `clients.claim()`。
- 开发环境不注册 Service Worker，避免干扰热更新。

### 已知风险

1. **缓存版本更新**：发布新版本时需要递增 `CACHE_NAME`，否则旧 Service Worker 缓存可能延迟新资源生效。
2. **离线范围有限**：当前预缓存首页、知识图谱、诊断页和体检页；工单、维修员工作台、管理员看板未完整预缓存，离线时会进入 `offline.html`。AI 与 `/api/` 功能必须联网。
3. **浏览器与部署限制**：Service Worker 需要 localhost 或 HTTPS；LocalStorage 中的工单、评价和草稿不会进入 Service Worker 缓存，换浏览器或清理站点数据后仍会丢失。
4. **首次安装开销**：Service Worker 安装时会抓取页面和 `/_next/static/` 资源，首次访问的安装阶段会额外消耗网络与缓存空间。

### 已知风险

1. **LocalStorage 非生产级持久化**：评价、工单和诊断草稿仍保存在浏览器，清除缓存或换设备会丢失；角色和评价也可被同源脚本修改。
2. **知识图谱规模扩展风险**：当前纯 SVG 一次渲染全部节点，25 条数据可用；知识库继续增长后可能出现纵向过长、移动端横向滚动和渲染性能压力，需要增加筛选、分组折叠或虚拟化。
3. **错误码覆盖有限**：识别依赖知识库现象关键词中已存在的错误码；未知错误码使用启发式故障类型，且当前不包含 OCR/截图识别。
4. **学习模式依赖模型追问**：若模型返回 `informationSufficient=true` 或 `followUpQuestions=[]`，步骤卡不会出现；学习进度也不会跨会话持久化。
5. **CSV 为当前浏览器快照**：导出的是当前 LocalStorage 工单，不是服务端全量数据；大数据量下浏览器内存和下载耗时需关注。
6. **浏览器能力差异**：语音识别、语音播报、MediaRecorder 视频生成依赖 Chrome/Edge 等浏览器支持，不支持时会隐藏或提示降级。
